Each tower a cannon has heard from, at the block its modem sits on. Positions are worked out entirely on the in-game computers — no distance ever reaches this website — so this list grows without adding any load here.

Four or more towers are needed, and at least one must sit well off the height of the others. A tower set that is flat cannot determine height at all, because your mirror image fits the measurements just as well, and clients will refuse rather than guess. Spread the towers far apart too: their spread governs accuracy far more than anything in the software. Above y=96 wireless range climbs from 64 blocks to 384, so a raised tower covers much more ground.

What each cannon's GPS engine is managing right now. Towers used is how many went into the fix; DOP is how many blocks of error each block of distance error becomes, so 1 is an ideal spread, under 10 is good, and it climbs as the towers flatten towards one plane — a flat set reads fragile, and one exactly in a plane is refused outright. Residual is how well the measurements agree, in blocks, and is the number that catches a tower that has been moved or mis-keyed. A tower listed as ignored has been left out on purpose — check it against the map.

Named reload mechanisms, saved here so a cannon computer can pull the list at first-boot setup and pick one, instead of the timings being typed in at every cannon. Kind is where in the firing sequence the reload happens, and that is what makes one mechanism behave differently from another.

A cannon computer reads this list once, when it is first configured, and keeps the timings it was given — so editing or deleting a preset never changes a cannon that is already set up.

Every firing order that has ended — whether it fired out or was stopped early — newest first. Each entry names the officer who ordered it, how many shots each gun actually fired, and which targets those shots went to.

A shot counts only once the cannon has reported it fired. Rounds a Stop withdrew before they were fired are listed separately as withdrawn, so a stopped barrage cannot read as though it fired rounds it never did.
