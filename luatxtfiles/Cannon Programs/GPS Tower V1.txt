-- ============================================================
-- GPS Tower — Regnum Aeternum
-- ============================================================
--
-- A lean, drop-in stand-in for ComputerCraft's stock `gps host`.
--
-- WHY REPLACE THE STOCK HOST?
--   Stock `gps host` redraws its terminal on EVERY request it answers — a
--   cursor reposition plus a print of a running counter:
--
--       nServed = nServed + 1
--       if nServed > 1 then term.setCursorPos(1, y - 1) end
--       print(nServed .. " GPS requests served")
--
--   Drawing to the terminal is one of the more expensive things a CC
--   computer can do, and a computer only gets about 5 ms of execution per
--   world tick. On a busy network — every cannon, every ship beacon and
--   every receiver pinging once a second — the towers burn a real slice of
--   that budget redrawing a counter, and a tower that overruns its budget is
--   paused and answers late or not at all. That is one of the reasons a large
--   network "lags" even though nothing is actually wrong with the radio.
--
--   This program speaks exactly the same protocol but redraws its status line
--   at most once every STATUS_INTERVAL seconds, no matter how many requests
--   arrive in between.
--
-- STAYING ALIVE (why a tower can go quiet, and what this does about it)
--   A tower is only useful while it is listening, and there are several ways
--   to stop listening by accident. This program is built so that none of them
--   is permanent:
--
--   * THE CHANNEL CAN BE CLOSED UNDERNEATH IT. `open` is a property of the
--     modem, not of this program: another program on the same computer,
--     `rednet`, a `closeAll`, or the modem being broken and replaced can all
--     leave us holding a modem that is no longer listening on 65534. A tower
--     that only opens the channel once at boot then answers nothing, for ever,
--     while its screen happily says it is fine. So the channel is VERIFIED
--     with `modem.isOpen` every status tick and re-opened whenever it is not.
--   * THE PERIPHERAL OBJECT CAN BE REPLACED. `modem` is re-wrapped from the
--     peripheral list on every check rather than cached for the life of the
--     program, so a modem whose Java-side object was swapped out is picked up.
--     (Channel state lives on the modem, so re-wrapping cannot lose it.)
--   * AN UNEXPECTED ERROR USED TO BE THE END OF THE TOWER. The serve loop now
--     runs under `pcall`: if anything throws, the tower counts it, re-attaches
--     and starts serving again instead of dropping to a shell prompt.
--   * SILENCE IS NOW VISIBLE. "Last ping" tells you the moment a tower stops
--     being asked for positions, and if nothing has been heard for
--     QUIET_ALERT seconds the tower re-arms the modem channel itself (close,
--     re-wrap, re-open) and says so on screen.
--
--   What none of this can fix is the chunk being unloaded: a ComputerCraft
--   computer only runs while the chunk it sits in is loaded. Unload that chunk
--   and the tower is powered off (so it answers nothing at all); load it again
--   and the computer boots and re-runs startup from the beginning. That is why
--   "Served" shows this boot's share AND a running total kept on disk, and why
--   "boot #" counts restarts: a tower that is being unloaded is visible as a
--   boot number climbing, rather than looking like a tower that does nothing.
--   Force-load the chunk (or keep the tower inside a permanently loaded area)
--   if the network has to work when nobody is standing next to it. A tower that
--   was shut down does NOT come back because the chunk was force-loaded after
--   the fact; it comes back when the chunk is loaded and the computer boots —
--   if it stays silent after that, this screen now tells you which of the two
--   it is: no pings arriving (a receiver-side problem, or the chunk is still
--   not ticking) versus pings arriving and not being answered (a modem fault,
--   which is counted here).
--
-- PROTOCOL — identical to stock, so the two are interchangeable
--   * Listen on channel 65534 (gps.CHANNEL_GPS).
--   * On a message whose payload is the string "PING", reply with the table
--     { x, y, z } on the reply channel the sender asked for.
--   Nothing else is sent, ever. This means:
--     - stock `gps.locate()` still works against this tower,
--     - stock `gps host` and this program can be mixed freely,
--     - and the leaner gpsnet client works with either.
--
-- INSTALL / RUN
--   It is a daemon: put it on the tower computer as `startup.lua`.
--
--       shell.run("gpstower", x, y, z)
--
--   or by hand to test:
--
--       gpstower <x> <y> <z>
--
--   The coordinates must be those of THE BLOCK THE MODEM IS ON, in whole
--   blocks. That is the point CC measures every distance from, so a tower
--   given the wrong block quietly ruins every fix in range. Stand on the
--   tower and read F3, or dig out the modem and read the block coordinates
--   directly. Give every tower its OWN block: two towers that report the same
--   coordinates are one tower as far as every client is concerned.
--
-- TOWER PLACEMENT
--   * Four or more towers are needed, and at least one must be well off the
--     plane of the others — a tower, a hill, a shaft, a mountain. A set of
--     towers all at one height cannot determine height at all (your mirror
--     image fits the measurements just as well), and every client will say so
--     rather than guess.
--   * Spread them far apart, and in height. CC's distances are exact, so even
--     a lopsided network solves exactly — but the flatter it is, the more it
--     leans on every tower's coordinates being right, and the more one moved
--     or mis-keyed tower costs you. Clients report this as a DOP.
--   * Above y=96 the wireless range climbs from 64 blocks to 384, so a raised
--     tower covers far more ground.
--   * KEEP THE CHUNK LOADED — see STAYING ALIVE above.
-- ============================================================

local VERSION = "1.1"

-- CC's standard GPS channel. Towers must listen here; clients ping here.
local GPS_CHANNEL = 65534

-- How often the status screen redraws. This is the only drawing this program
-- ever does, and it is deliberately slow. It is also the self-check cadence:
-- every tick verifies the modem is still there and still listening.
local STATUS_INTERVAL = 5

-- With receivers pinging once a second, hearing NOTHING for this long means
-- something is wrong (the channel was closed, or the modem is confused), so
-- the tower re-arms itself. It is deliberately longer than any plausible quiet
-- spell, so an idle network is never churned.
local QUIET_ALERT = 30

local tArgs = { ... }

local function usage()
  print("GPS Tower " .. VERSION)
  print("")
  print("Usage:  gpstower <x> <y> <z>")
  print("")
  print("Acts as a GPS host: it answers position pings on channel " .. GPS_CHANNEL)
  print("so that computers, ships and cannons can work out where they are.")
  print("")
  print("Give it the coordinates of the block the MODEM is on, in whole")
  print("blocks — that is the point every distance is measured from, so a")
  print("tower given the wrong block quietly ruins every fix in range.")
  print("")
  print("Recommended startup.lua:")
  print('    shell.run("gpstower", ' .. 'x, y, z' .. ")")
end

local x = tonumber(tArgs[1])
local y = tonumber(tArgs[2])
local z = tonumber(tArgs[3])
if not (x and y and z) then
  usage()
  return
end
-- Whole blocks only. A fractional coordinate would put a constant offset on
-- every distance measured from this tower, which nothing downstream could
-- detect or correct for.
x, y, z = math.floor(x + 0.5), math.floor(y + 0.5), math.floor(z + 0.5)

-- ------------------------------------------------------------
-- Helpers
-- ------------------------------------------------------------

local function findWirelessModem()
  local names = peripheral.getNames()
  for i = 1, #names do
    local side = names[i]
    if peripheral.getType(side) == "modem" then
      local ok, m = pcall(peripheral.wrap, side)
      if ok and m then
        local okw, wireless = pcall(m.isWireless)
        if okw and wireless then return m, side end
      end
    end
  end
  return nil, nil
end

local function formatUptime(seconds)
  seconds = math.max(0, math.floor(seconds))
  local h = math.floor(seconds / 3600)
  local m = math.floor((seconds % 3600) / 60)
  local s = seconds % 60
  return ("%d:%02d:%02d"):format(h, m, s)
end

local function agoText(seconds)
  if seconds == nil then return "never" end
  seconds = math.max(0, math.floor(seconds))
  if seconds < 60 then return seconds .. "s ago" end
  if seconds < 3600 then return math.floor(seconds / 60) .. "m ago" end
  return formatUptime(seconds) .. " ago"
end

local function termWidth()
  local ok, w = pcall(term.getSize)
  if ok and type(w) == "number" and w > 8 then return w end
  return 51
end

local function fit(s, width)
  s = tostring(s or "")
  if #s <= width then return s end
  return s:sub(1, width - 1) .. "…"
end

-- ------------------------------------------------------------
-- Counters and the event log
-- ------------------------------------------------------------
-- Declared before the on-disk state, because the state file records this
-- boot's share of the count.

local modem, modemSide = nil, nil
local served = 0          -- usable pings answered this boot
local sentReplies = 0     -- replies the modem accepted
local failedReplies = 0   -- replies that threw (a modem fault)
local unusable = 0        -- traffic on our channel that was not a position ping
local reopens = 0         -- times the channel had to be re-armed
local errors = 0          -- unexpected errors survived
local lastError = nil
local started = os.clock()
local lastPingAt = nil    -- last usable ping heard
local lastWatchdogAt = nil

-- A tiny rolling log, so a recovery is visible on the screen rather than only
-- in the operator's imagination. Two lines is all the room there is.
local NOTES_MAX = 2
local notes = {}
local function note(text)
  notes[#notes + 1] = tostring(text)
  while #notes > NOTES_MAX do table.remove(notes, 1) end
end

-- ------------------------------------------------------------
-- State
-- ------------------------------------------------------------
-- Counters survive a restart. A tower that gets its chunk unloaded is powered
-- off and boots again when the chunk comes back, so anything held only in
-- memory restarts from zero — which looks exactly like "the tower is doing
-- nothing" on this screen. The running total and the boot count live on disk
-- so a restart is visible for what it is.
local STATE_PATH = "gpstower_state.txt"
local state = { total = 0, boots = 0 }

local function readState()
  if not fs.exists(STATE_PATH) then return end
  local ok = pcall(function()
    local f = fs.open(STATE_PATH, "r")
    if not f then return end
    local raw = f.readAll()
    f.close()
    local parsed, data = pcall(textutils.unserialize, raw)
    if parsed and type(data) == "table" then
      state.total = tonumber(data.total) or 0
      state.boots = tonumber(data.boots) or 0
    end
  end)
  if not ok then state.total, state.boots = 0, 0 end
end

-- Written on every status tick (a handful of bytes every STATUS_INTERVAL
-- seconds), so at most one tick of counting is ever lost to a shutdown. Never
-- allowed to throw: a tower that cannot save its counters must still serve.
local function writeState()
  pcall(function()
    local f = fs.open(STATE_PATH, "w")
    if not f then return end
    f.write(textutils.serialize({ total = state.total + served, boots = state.boots }))
    f.close()
  end)
end

-- ------------------------------------------------------------
-- Modem attachment
-- ------------------------------------------------------------
-- Called at boot, on every status tick, whenever a peripheral comes or goes,
-- and again after an unexpected error. It does three things, every time:
--
--   1. looks the modem up FRESH — `peripheral.wrap` is cheap, and re-wrapping
--      is what recovers from a peripheral object that was replaced;
--   2. checks the channel is REALLY open with `modem.isOpen`, and re-opens it
--      if it is not, because a channel can be closed underneath us and a tower
--      that never reopens never answers again;
--   3. throws away a modem that cannot hold the channel, so the next attempt
--      starts from a clean lookup rather than trusting a dead wrapper.
--
-- Returns true when this tower is listening.

local function channelOpen(m)
  if not m then return false end
  local ok, open = pcall(m.isOpen, GPS_CHANNEL)
  if not ok then return nil end        -- stale wrapper: the peripheral is gone
  return open == true
end

local function attach()
  local found, side = findWirelessModem()
  if not found then
    if modem then pcall(function() modem.close(GPS_CHANNEL) end) end
    if modemSide then note("Modem on '" .. tostring(modemSide) .. "' went away") end
    modem, modemSide = nil, nil
    return false
  end

  -- The normal path: same side, and the channel is verifiably open. Nothing to
  -- do at all, so a healthy tower touches nothing.
  if modemSide == side and channelOpen(found) == true then
    modem = found
    return true
  end

  local ok, opened = pcall(found.open, GPS_CHANNEL)
  -- `open` reports an already-open channel as false, which is not a failure,
  -- so the channel itself is what we check rather than the return value.
  if not ok or channelOpen(found) ~= true then
    note("Cannot listen on modem '" .. tostring(side) .. "' — retrying")
    modem, modemSide = nil, nil
    return false
  end

  if modemSide == side then
    -- We were already listening on this modem and had to open it again: the
    -- channel was closed underneath us, which is exactly the fault that used
    -- to leave a tower silent for ever. Say so, loudly.
    reopens = reopens + 1
    note("Re-opened channel " .. GPS_CHANNEL .. " (closed underneath us)")
  elseif modemSide ~= nil then
    note("Modem moved from '" .. tostring(modemSide) .. "' to '" .. tostring(side) .. "'")
  else
    note("Listening on modem '" .. tostring(side) .. "'")
  end

  modem, modemSide = found, side
  return true
end

-- Deliberately start a modem over from nothing: close the channel, forget the
-- wrapper, and attach again. Used by the watchdog, so a modem that has gone
-- deaf without its channel state changing gets a genuine reset.
local function forceReattach(reason)
  if modem then pcall(function() modem.close(GPS_CHANNEL) end) end
  modem, modemSide = nil, nil
  note(reason)
  attach()
end

-- A tower that is listening but hearing nothing is either genuinely alone (no
-- receiver in range) or holding a modem that is no longer delivering. The
-- second is recoverable, so after QUIET_ALERT seconds we do the only thing
-- that can recover it.
local function watchdog()
  if not modemSide then return end
  local now = os.clock()
  local baseline = lastPingAt or started
  if (now - baseline) < QUIET_ALERT then return end
  if lastWatchdogAt and (now - lastWatchdogAt) < QUIET_ALERT then return end
  lastWatchdogAt = now
  forceReattach("Quiet for " .. QUIET_ALERT .. "s — re-arming the modem")
end

-- ------------------------------------------------------------
-- Status screen
-- ------------------------------------------------------------
-- The only drawing this program does. Everything here is derived from counters
-- held in memory, so it costs one terminal repaint every STATUS_INTERVAL
-- seconds no matter how busy the network is. Wrapped in pcall: a terminal in a
-- strange state must not be able to stop the tower from serving.

local function drawStatus()
  pcall(function()
    local width = termWidth()
    local now = os.clock()
    term.clear()
    term.setCursorPos(1, 1)

    print("=== GPS Tower " .. VERSION .. " ===")
    print("Position:  " .. x .. ", " .. y .. ", " .. z)

    if modemSide then
      print(fit("Modem:     " .. modemSide .. "  — channel " .. GPS_CHANNEL .. " open", width))
    else
      print("Modem:     none attached — fit a wireless modem")
    end

    print("Uptime:    " .. formatUptime(now - started) .. "  ·  boot #" .. state.boots)
    print("Served:    " .. served .. " ping(s) this boot  ("
      .. (state.total + served) .. " total)")
    print("Last ping: " .. agoText(lastPingAt and (now - lastPingAt) or nil))
    print("")

    if modemSide then
      local healthy = lastPingAt ~= nil and (now - lastPingAt) < QUIET_ALERT
      if healthy then
        print("Status:    OK — answering pings")
      else
        print("Status:    QUIET — no usable ping heard")
        print(fit("           for " .. math.floor(now - (lastPingAt or started))
          .. "s; the modem is re-armed every " .. QUIET_ALERT .. "s.", width))
        print("           Check a receiver is in range, or that the")
        print("           chunk this tower sits in is loaded and ticking.")
      end
    else
      print("Status:    waiting for a wireless modem — one will be")
      print("           picked up automatically when it appears.")
    end

    print("")
    print(fit("Replies:   " .. sentReplies .. " sent, " .. failedReplies .. " failed", width))
    print(fit("Recovery:  " .. reopens .. " re-open(s), " .. errors .. " error(s) survived", width))
    if unusable > 0 then
      print(fit("Ignored:   " .. unusable .. " other message(s) on " .. GPS_CHANNEL, width))
    end
    if lastError then
      print(fit("Last error:" .. lastError, width))
    end
    for i = 1, #notes do
      print(fit("Log:       " .. notes[i], width))
    end
  end)
end

-- ------------------------------------------------------------
-- Serve
-- ------------------------------------------------------------

readState()
state.boots = state.boots + 1
writeState()

attach()
drawStatus()

-- The serve loop, inside `pcall`. The guarded function never returns
-- normally: it only ever comes back by throwing, so the outer loop is the
-- daemon's shell — an unexpected error costs one second and a re-attach, never
-- the tower.

local statusTimer = os.startTimer(STATUS_INTERVAL)

while true do
  local ok, err = pcall(function()
    while true do
      local event, p1, p2, p3, p4, p5 = os.pullEvent()

      if event == "modem_message" then
        local msgSide, channel, replyChannel, message, distance = p1, p2, p3, p4, p5
        -- Only answer pings that arrived on our own modem (with one modem that
        -- is always the case, but it keeps the reply's distance honest if a
        -- second modem is ever fitted), on the GPS channel, carrying the exact
        -- word "PING", and with a distance present (a wired modem reports
        -- none).
        --
        -- `distance ~= nil` rather than a plain truthiness test: a tower
        -- standing on the same block as the computer it is answering measures
        -- ZERO, and a truthiness test would have exactly that tower refuse to
        -- answer for ever.
        if modem and msgSide == modemSide and channel == GPS_CHANNEL then
          if message == "PING" and distance ~= nil then
            served = served + 1
            lastPingAt = os.clock()
            local sent = pcall(function() modem.transmit(replyChannel, GPS_CHANNEL, { x, y, z }) end)
            if sent then sentReplies = sentReplies + 1 else failedReplies = failedReplies + 1 end
          else
            -- Something else is talking on the GPS channel. Counted, not acted
            -- on: the channel is shared, and a foreign program on it is worth
            -- being able to see.
            unusable = unusable + 1
          end
        end

      elseif event == "timer" and p1 == statusTimer then
        attach()
        watchdog()
        writeState()
        drawStatus()
        statusTimer = os.startTimer(STATUS_INTERVAL)

      elseif event == "peripheral" or event == "peripheral_detach" then
        attach()
      end
    end
  end)

  errors = errors + 1
  lastError = tostring(err)
  note("Recovered from an error")
  sleep(1)
  attach()
  drawStatus()
end
